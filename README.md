# HR-IQ-EQ-Digital-Examination-System

HR IQ &amp; EQ Digital Examination System is a full-stack web application developed to digitalize the IQ and Emotional Intelligence (EQ) assessment process for new recruits. The system supports candidate registration, digital IQ and EQ question papers, answer submission, automated evaluation, and results management. It is built using React, Node.js, Express.js, and Microsoft SQL Server.
